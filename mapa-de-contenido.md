# The Dog Owners Hub — Mapa de Contenido (versión web vs. versión avanzada)

Este documento organiza los 31 temas ya escritos (nivel "blog") en los conjuntos que
formarán los módulos del futuro libro/curso. El orden aquí es el orden **lógico/progresivo**
para el producto de pago — no tiene por qué coincidir con el orden de publicación en la web,
que sigue rotando por categoría.

Para cada conjunto, la versión avanzada añadirá lo que un artículo de blog no tiene espacio
para dar: ejercicios paso a paso, plantillas/checklists descargables, casos prácticos,
preguntas de autoevaluación, y contenido "interactivo" con el perro (no solo teoría).

## Cómo se traduce esto al libro/curso

- **Estructura del producto**: los 6 conjuntos = 6 módulos/capítulos, en este orden progresivo
  (cachorro → entrenamiento → psicología/comportamiento → convivencia → ciclo de vida → equipo).
- **Diferenciador frente a la web gratuita**: cada módulo avanzado añade ejercicios prácticos,
  plantillas (ej. calendario de socialización, checklist de compra por etapa), casos reales,
  y referencias ampliadas — no es solo "más largo", es más aplicable.
- **Publicación en la web**: sigue como hasta ahora, rotando categorías para SEO, sin seguir
  este orden — este mapa es solo para la construcción del producto de pago.
